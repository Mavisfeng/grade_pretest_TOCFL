# TOCFL 準備級模擬試題 成績評分表

這個專案將 TOCFL（華語文能力測驗）準備級模擬試題的手寫答案卡掃描檔，比對正確答案，
並依官方對照表換算為聽力／閱讀測驗成績，輸出成一份 Excel 成績單。

## 內容物

```
tocfl-grading/
├── grade.py              # 產生成績表的 Python 腳本（含所有學生作答資料與評分邏輯）
├── requirements.txt       # Python 套件需求（openpyxl）
├── output/
│   └── TOCFL成績評分表.xlsx   # 執行後產生的成績表（已內附範例輸出）
└── README.md
```

## 使用方式

```bash
pip install -r requirements.txt
python3 grade.py
```

執行後會在 `output/` 資料夾產生（或覆蓋）`TOCFL成績評分表.xlsx`，內含兩個工作表：

- **成績明細**：每位學生每一題的作答、正確答案、是否正確（O/X），錯誤處以粉紅色標示。
- **成績總表**：每位學生的聽力／閱讀答對題數與換算後的測驗成績。

## 資料來源與流程

1. **答案卡影像**：每位學生的 TOCFL 答案卡照片（`.jpg`），逐題以肉眼辨識鉛筆塗黑的選項。
2. **正確答案**：依據官方模擬試題答案卡（Answer Key of the Mock Test）人工輸入至 `grade.py` 的 `key` 變數。
3. **成績對照表**：依據官方「測驗成績對照表」（答對題數 → 測驗成績），人工輸入至 `grade.py` 的
   `L_table`（聽力）與 `R_table`（閱讀）變數。
4. **評分邏輯**：`grade.py` 逐題比對每位學生的作答與正確答案，計算答對題數，
   再查表換算為聽力與閱讀測驗成績，最後輸出為 Excel 檔案。

## 重要限制與使用須知

⚠️ **本評分表為人工目視判讀掃描答案卡的結果，並非透過校準過的 OMR（光學閱卡）掃描器產生**，
因此存在下列已知風險，正式使用前請務必抽查核對：

- 部分答案卡有塗改、雙重塗黑或字跡模糊的情況，判讀時以最合理的判斷為準，
  但無法保證 100% 準確。
- 少數學生（如林裕鈞、沈安達）的照片為橫向或顛倒拍攝，已經程式旋轉校正後再行判讀。
- 有個別學生（如沈美芬）的部分題目為劃記後又劃掉（可能表示該題作廢或更改答案），
  這類情況目前一律視為「未作答」計為錯誤，如有正式的廢題公告，請自行調整計分。
- 建議正式使用前，至少抽查 10-20% 的答案卡與 Excel 明細比對，確認判讀正確。

## 新增更多學生

若要新增學生成績，在 `grade.py` 的 `students` 字典中依相同格式新增一筆：

```python
"新學生姓名": {
    1:"B",2:"C", ... 50:"A",
},
```

鍵為題號（1–50，1–25 為聽力，26–50 為閱讀），值為該題學生作答的選項（A/B/C）。
新增後重新執行 `python3 grade.py` 即可更新成績表。
